# 事故复盘与防复发（09-02 前端批量改写事故）

## 事故
用跨行正则批量给 5 个 SFC 加列显隐时，Economy/Stocktakes/Flows 三文件的 `</script>` 及部分业务代码被吞（文件尾部截断），Economy 页无数据、盘点/流程页逻辑全失。

## 已复原
- Economy.vue：完整重写（筛选+分页+导出+列功能），浏览器验证 9633 条数据正常
- Flows.vue：完整重写（列表/类型状态筛选/发起申请(资产搜索)/批准驳回）
- Stocktakes.vue：完整重写（任务列表/新建圈定/扫码盘点/差异报表），已对齐真实 API（scan 返回 {result,asset_tag,name}；stats={total,found,missing,unexpected,progress}）

## 防复发铁律
1. 批量改 SFC 一律用 patch 精准锚点，禁用跨行正则尾部替换
2. 改完必检：文件尾有 `</script>`/`</style>`、构建通过
3. 生产 runserver 必须 `--noreload`（autoreload 子进程会吞 wsgi 后台线程）
4. LocMemCache 进程隔离：测缓存必须走 HTTP，`docker exec python` 是独立进程必误判 miss
